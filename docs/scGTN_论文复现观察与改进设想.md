# scGTN 论文复现观察与改进设想

**研究记录｜阶段：论文阅读与源码审查，基线实验待验证**  
**日期：2026 年 11 月 23 日**  
**研究对象：** Wu 等，*scGTN: Deep Siamese Graph Transformer Network for Single-cell RNA Sequencing Clustering*，IJCAI 2026。

## 研究概述

在阅读 scGTN 论文和 `preprocess.py`、`utils.py`、`model.py` 的过程中，我重点关注了**细胞图的构建依据、边权重是否进入注意力计算，以及最短路径编码是否充分表达细胞间关系**。初步发现若干论文描述与公开代码实现不完全一致的地方，并据此形成两个主要实验设想：**边权重感知 GAT** 与 **连续相似度增强的 Transformer 结构嵌入**。

本文是阶段性研究记录，**不是已经取得性能提升的实验报告**。下文区分“代码可观察事实”“论文—代码差异”和“个人假设”；性能结论需在官方基线成功复现后验证。

## 一、论文描述与代码实现的差异及待核查项

| 观察点 | 论文或预期设计 | 公开代码中的实现/观察 | 当前判断 |
|---|---|---|---|
| KNN 构图相似度 | 论文描述用 Pearson 相关系数构建细胞关系 | `build_knn_graph()` 对特征按行 L2 归一化，再通过矩阵乘法计算**余弦相似度** | **可核查差异**；是否影响聚类需实验比较 |
| 双视图表达扰动 | 论文公式分别记作 X̃¹、X̃² | `GraphAugmentation.__call__()` 生成一份 `X_aug`，同时生成两张不同的增强图 `adj_r`、`adj_d` | **实现差异**；不同视图主要由图结构区分 |
| GAT 中的边权重 | 预处理保留加权邻接矩阵 | `dense_to_sparse(adj)` 得到的边权重被 `_` 丢弃，`GATConv` 只接收 `edge_index` | **确认的代码现象**；GAT 利用边的存在性，但未显式输入连续权重 |
| Hop 距离 | 论文强调利用最短路径丰富细胞间结构信息 | `utils.py` 从输入邻接矩阵选 Top-k，再在同一图上计算无权最短路径 | **潜在信息退化**；需要统计 Hop ID 分布 |
| 视图编码器共享参数 | “Siamese”容易理解为两支网络全部共享参数 | GAT 编码器为同一实例；`encoder1`、`encoder2` 是两套 Transformer | **架构细节**；不能简单概括为全模型共享 |
| 邻域输出池化 | 论文描述邻域序列的均值池化 | `SingleViewEncoder` 计算了 `BertPooler` 输出，但主模型取 `outputs[0].mean(dim=1)` | **代码细节**；BERT Pooler 的结果未用于最终细胞向量 |
| 双视图最终融合 | 论文表达式为两个视图平均 | 代码使用 `sigmoid(fusion_weight)` 的可学习标量加权融合 | **实现差异**；可考察固定与可学习融合的影响 |

### 1.1 为什么 Pearson 与 Cosine 的差别值得关注

Pearson 相关系数先对每个细胞的表达向量**减去该向量的均值**，再比较变化模式；余弦相似度直接比较向量方向。减均值的直观作用是削弱表达向量整体基线差异，突出相对高低变化。因此，两者得到的 Top-k 近邻可能不同。这里不预设 Pearson 一定更好，后续需保持其余条件一致进行对比。

### 1.2 Hop 信息可能退化的原因

在 `compute_position_and_hop_ids()` 中，邻居由 `adj_dense[i, :]` 的权重排序得到，而最短路径图同样由 `adj_dense > 0` 构建。如果选中的邻居在该图中有正权重，它与中心节点直接相连，其无权最短路径就是 **1 hop**；中心节点自身为 **0 hop**。当选中零权重节点时，才可能出现多跳距离或不连通标记。因此，应检查实际 Hop ID 的频数，而不能直接断言所有节点都只有 0/1。

View 2 使用 PPR 扩散及阈值处理后的邻接矩阵。图扩散可能将原来的间接联系写成新的非零连接，随后在该扩散图上求无权最短路径，会进一步弱化原始多跳关系。**这是假设，有待通过原始图与扩散图的 Hop 分布对照证实。**

## 二、我的疑惑、研究假设与新实验设计

### 2.1 疑惑 A：为什么已有边相似度，却让 GAT 重新学习邻居重要性？

初始图依据表达相似度建立边；View 1 对边进行筛除和归一化，View 2 通过 PPR 得到扩散权重。进入 GAT 时，代码仅将边索引传入 `GATConv`，没有显式传递边权重。图结构告诉模型**哪些细胞能够通信**，而连续边权重还可以告诉模型**这些关联原本有多强**；GAT 注意力则学习**当前训练目标下应该关注谁**。三者信息并不等价。

**研究假设 H1：** 在控制模型结构和训练条件的前提下，显式引入连续边权重，有可能提高聚类精度或稳定性；也可能因表达噪声、归一化权重或 PPR 权重的尺度差异而降低性能。

**实验 A：Edge Weight-aware GAT**

| 实验组 | 方法 | 与原始模型的主要区别 |
|---|---|---|
| A0 Baseline | 官方 GAT，只输入 `edge_index` | 不使用连续边权重 |
| A1 Edge Feature GAT | `GATConv(edge_dim=1)`，传入 `edge_attr` | 让边权重参与注意力打分 |
| A2 Learnable Edge Prior | 注意力 logits 加入 `λ · g(wᵢⱼ)`，λ 可学习 | 将权重视为可调节先验 |

一种候选形式为：

\[
 e'_{ij}=e_{ij}+\lambda\,g(w_{ij}),\qquad \alpha_{ij}=\operatorname{softmax}_{j}(e'_{ij}).
\]

其中 `g` 可以是经过数值变换的标量函数或小型 MLP。对于归一化后可能接近零的正权重，若使用 `log(w+ε)` 必须处理数值稳定性；对 View 1 的归一化权重与 View 2 的 PPR 权重，不能未经校准就假设语义相同。

### 2.2 疑惑 B：相同 Hop ID 对应同一向量，是否损失了细胞关系的强弱信息？

`nn.Embedding` 对相同整数 ID 使用同一个可学习向量。因此两个细胞若都距离中心 1 hop，其 Hop Embedding 相同，即使一条边权重为 0.95，另一条为 0.55。它们的**最终 Transformer 输入并不必然相同**，因为表达嵌入和位置嵌入仍可能不同；缺失的是 Hop 分量内部对连续相似度的区分能力。

**研究假设 H2：** 在表达嵌入 E、位置嵌入 P、Hop 嵌入 H 之外加入连续关联强度嵌入 S，可能保留更多细胞关系信息。

原始融合：

\[
Y=E+P+H.
\]

候选改进：

\[
S_{ij}=\operatorname{MLP}(s_{ij}),\qquad Y_{ij}=E_{ij}+P_{ij}+H_{ij}+S_{ij}.
\]

此处 `sᵢⱼ` 必须明确取自哪个图以及代表什么：如果是无直接边的细胞对，原始邻接矩阵的零值不能被误解释成“相似度为零”；可另行计算原始表达的余弦/Pearson 相似度，或使用经过定义的路径关联强度。

更深入的候选方案是把关系特征加到 Transformer 注意力 logits：

\[
\operatorname{logit}_{ij}=\frac{q_i k_j^T}{\sqrt{d_k}}+b_s(s_{ij})+b_h(h_{ij}).
\]

注意：若只具有“中心—邻居”的标量关系，则还不能直接构造完整的 `(k+1)×(k+1)` 注意力偏置矩阵；需要明确邻域序列中**任意两个位置**之间的相似度/图距离。这是实现前必须解决的定义问题。

**实验 B：结构信息消融**

| 实验组 | 输入特征融合 | 希望回答的问题 |
|---|---|---|
| B0 Baseline | E + P + H | 官方参照 |
| B1 | E + P + H + S | 连续边强度是否带来增益 |
| B2 | E + P + S | 去掉 H 后连续强度能否替代它 |
| B3 | E + H + S | 去掉 P 后模型表现如何 |
| B4（进阶） | 注意力 logits 加关系偏置 | 显式关系偏置是否优于输入相加 |

### 2.3 实验执行顺序与控制原则

**先复现，再改进。** 第一阶段锁定官方源码版本和 Muraro 数据集，保存官方配置、随机种子、环境及数据预处理输出。第二阶段每次只更改一个因素；主实验固定同一份输入、训练轮数、优化器、损失权重、聚类数以及评价方法。第三阶段在多个随机种子下重复并报告均值与标准差。

**评价记录：** ACC、NMI、ARI、训练总耗时、峰值内存、参数量、各损失曲线、运行种子；同时报告 Hop ID 的频数与不同视图的边权重分布。对于 A/B 两组实验，尽量比较单独改进与组合改进，避免将两类改动同时引入而无法归因。

**当前不能下的结论：** 不能断言“边权重一定优于 Hop”“GAT 不使用边权重一定是错误”“论文代码差异必然导致结果下降”，这些都属于实验假设。

## 三、我认为巧妙的模型设计及其意义

### 3.1 自环与残差连接：保留细胞自身信息

在图归一化中加入单位矩阵 `torch.eye(n)` 相当于添加自环，让后续图传播能够保留自身特征的信息通道；模型内的残差连接则进一步为原始特征提供直接路径。二者作用相关，但不完全相同：**自环属于图连接设计，残差属于网络结构设计**。

### 3.2 共享 GAT + 独立 Transformer：统一底层编码与视图特异学习

两张增强图通过同一个 GAT 提取初始图特征，使底层映射保持一致；两个独立的 Transformer 分支则分别建模各自邻域的表达、位置和路径结构。这种“部分共享、部分独立”的做法在统一表征基础与保留视图差异之间提供了一个折中。其效果仍应由参数共享消融确认。

### 3.3 表达、位置、路径的统一维度相加

`GraphBertEmbeddings` 将 GAT 特征线性映射、Position ID 与 Hop ID 分别映射到相同隐藏维度后相加：`Y = E + P + H`。这一方式让 Transformer 在后续自注意力中联合处理生物表达信息与结构上下文，输入形状保持为 `(N, k+1, d)`。它简单、易于训练，但也为加入连续关系强度 S 留出了自然接口。

### 3.4 邻域序列 Mean Pooling 与双视图融合

主模型选择 `sequence_output.mean(dim=1)` 为每个中心细胞生成单个表示，而非直接使用 BERT Pooler 输出。两个视图后续还可通过一个可学习标量融合；该设计使模型有机会自动调整两张图的贡献，但单个全局标量无法表达不同细胞各自的融合偏好。这可作为后续独立的研究问题，而不宜在第一轮消融中混入。

## 四、建议与导师讨论的问题

1. **优先级：** 先验证 GAT 的边权重感知，还是先检查 Hop ID 的实际退化程度？从实施风险看，我倾向先做 Hop 分布诊断，再做 A1 边特征实验。
2. **关系定义：** 额外的 S 应来自原始表达相似度、归一化邻接权重，还是 PPR 强度？三者生物与图论含义不同。
3. **实验范围：** 第一轮在 Muraro 上完成基线和单因素消融，若有效再扩展到更多细胞数据集，是否合理？
4. **科研目标：** 目前以严谨复现和可归因的小改动为主，暂不以“显著超越论文”为预设目标。
